# คอนโซลเฝ้าระวังศูนย์พักพิงตาก (ต้นแบบ)

ต้นแบบหน้าจอของ **ระบบข้อมูลสุขภาพและเฝ้าระวังโรค ศูนย์พักพิงชั่วคราวสำหรับผู้อพยพ 3 แห่ง จ.ตาก**
(แม่หละ · อุ้มเปี้ยม · นุโพ) — พัฒนาโดย OneSpace Corporation Co., Ltd.

> ⚠️ **ตัวเลขทั้งหมดเป็นข้อมูลจำลอง** สำหรับทบทวนโครงสร้างหน้าจอและนิยามตัวชี้วัดก่อนพัฒนาจริง
> ยังไม่ได้เชื่อมต่อกับ Hospital OS ของศูนย์พักพิง และไม่มีข้อมูลผู้ป่วยจริงอยู่ในไฟล์นี้

## เนื้อหา

ไฟล์เดียวจบ ไม่มี build step ไม่มี dependency นอกจากฟอนต์จาก Google Fonts

| ไฟล์ | คำอธิบาย |
|---|---|
| `index.html` | ทั้งระบบ (HTML + CSS + JS + ข้อมูลจำลอง) |

5 หน้าในคอนโซลเดียว เลือกดูรายศูนย์ได้ทุกหน้า และปรับขนาดตัวอักษรได้ (จำค่าไว้ใน localStorage)

1. **ภาพรวม** — เหตุการณ์ที่เข้าเกณฑ์แจ้งเตือน เรียงตามเวลาคงเหลือก่อนครบกำหนดยืนยัน 48 ชม. + คิวงาน
2. **อนามัยแม่และเด็ก** — แนวโน้ม 12 เดือน และตัวชี้วัด 15 ตัวเทียบเป้าหมาย
3. **โรคติดเชื้อทางเดินอาหาร** — เส้นโค้งระบาด อุบัติการณ์เทียบเกณฑ์ การกระจายรายโซน ทะเบียนผู้ป่วย
4. **โรคไม่ติดต่อเรื้อรัง** — ลำดับขั้นการดูแล (care cascade) และอัตราการควบคุมความดันโลหิต
5. **คุณภาพข้อมูล** — จังหวะการส่งรายสัปดาห์ คะแนน 5 มิติ และเรคคอร์ดที่ไม่ผ่านกฎตรวจสอบ

นิยามตัวชี้วัดอ้างอิง WHO EWARN Implementation Guidelines 2012, UNHCR Standards and
Indicators Guide 2019 และ WHO HEARTS

## การนำขึ้นใช้งาน

**Vercel**

```bash
git init
git add .
git commit -m "Tak shelter surveillance console (prototype)"
git remote add origin https://github.com/<user>/<repo>.git
git push -u origin main
```

แล้ว import repo ใน Vercel — เป็น static site ไม่ต้องตั้ง Framework Preset (เลือก *Other*),
Build Command และ Output Directory ปล่อยว่างไว้

**GitHub Pages** — เปิด Pages ชี้ไปที่ branch `main` โฟลเดอร์ `/ (root)` ไฟล์ `.nojekyll`
มีอยู่แล้วเพื่อไม่ให้ Jekyll ประมวลผลซ้ำ

## หมายเหตุด้านความเป็นส่วนตัว

หน้าจอนี้ออกแบบให้สอดคล้องกับหลักของโครงการ คือ **ไม่มีข้อมูลระบุตัวบุคคลออกจากศูนย์พักพิง**
ทะเบียนผู้ป่วยในหน้าโรคติดเชื้อทางเดินอาหารจึงแสดงเพียงรหัสนิรนาม (PERSON_UID ที่ทำ HMAC
ที่ฝั่งศูนย์) ช่วงอายุ เพศ และรหัสโซน ไม่มีชื่อ เลขประจำตัว 13 หลัก เลขพาสปอร์ต หรือ HN

ไฟล์นี้ตั้ง `<meta name="robots" content="noindex">` ไว้ เพื่อไม่ให้ search engine เก็บหน้า
ถ้าต้องการจำกัดผู้เข้าถึง ให้วางไว้หลังระบบล็อกอินของ Demo Portal แทนการเปิดเป็น public URL
